# 素材来源与授权

## 当前状态：无外部素材

本项目**不包含任何图片、音频、字体文件**。界面上所有元素都是 pygame 基础图元现场绘制：

| 元素 | 实现方式 |
| --- | --- |
| 方块 / 面板 | `pygame.draw.rect`（含圆角与边线） |
| 数字 1~8 | `pygame.font.Font(None, size)` 默认字体渲染 |
| 小旗子 | `pygame.draw.line` + `pygame.draw.polygon` |
| 地雷 | `pygame.draw.circle` + 八向辐射线 |
| 配色 | `minesweeper/theme.py` 中的手写 RGB |

因此仓库不存在第三方素材的版权问题，也不依赖运行时下载。

## 将来如果要引入素材

务必在这个文件里逐条登记，格式：

```
文件名: assets/xxx.png
来源: 站点名 + 具体链接
授权: CC0 / CC-BY-4.0 / 商用许可（写明是否需要署名）
用途: 例如 "地雷图标"
```

原则：

1. 优先使用 CC0 / 明确可商用的素材，避免来源不明的"网上找的图"；
2. 不使用其他游戏（尤其是有 IP 的付费游戏）的原画、贴图、音效；
3. 需要署名的素材，在 README 或游戏内 About 中保留署名。
